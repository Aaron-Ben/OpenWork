# OpenWork Desktop

OpenWork Desktop is the Tauri + React + TypeScript client for OpenWork.

## 中文

### 运行

```bash
pnpm install
pnpm tauri dev
```

### 构建

```bash
pnpm tauri build
```

### 技术栈

- Tauri 2
- React
- TypeScript
- Vite
- pnpm
