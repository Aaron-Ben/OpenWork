# Agent Note: 会话列表、未读数与侧栏导航

Status: implemented

## 问题

第 3a 步的侧栏把群聊与 Agent 分成两个列表，两个空列表叠在一起时显得空洞，也看不出哪个房间有新消息、最后说了什么。群聊多起来以后，用户需要：

- 一个按最近活动排列的会话列表，看到每个房间最后一条消息与有几条没读；
- 分别浏览群聊与联系人（Agent）；
- 从一个 Agent 出发，把它加进已有的群聊。

## 决策

2026-10-05 讨论，设计稿 `apps/desktop/out/mockups/step3-navigation.html`（不在 git 中）。用户选择方案 B，并要求群聊头像围成一个环、做未读数与“加入群聊”；没有给出更多理由。

**布局（方案 B）**

- 两栏：侧栏顶部是“消息 / 群聊 / 联系人”分段，右侧始终是聊天（`apps/desktop/src/components/Sidebar.tsx`）。“消息”的分段上显示未读总数。
- 消息：私聊与群聊混在一起，按最后活动排列；每项有头像、名字、时间、预览与未读数；房间里有 Agent 在回复时，预览换成“某某 回复中…”（`apps/desktop/src/lib/conversations.ts`）。
- 群聊与联系人是两份目录，点击任何一项都打开对应的聊天。启动时三份列表都到齐后，默认打开最近活跃的会话，只定这一次：之后列表随新消息重新排序，打开的房间不跟着变，否则别的房间来了消息会换掉正在看的房间、丢掉草稿并把它记为已读（提交前的评审发现）。还没有 Agent 时，右侧是三步引导（`apps/desktop/src/App.tsx` 的 `Welcome`）。
- 侧栏顶部（设计稿 `apps/desktop/out/mockups/sidebar-header.html` 的方案 B，用户选择）：系统红黄绿按钮那一行的右侧是“新建”图标按钮，点开是新建 Agent 与新建群聊的菜单；下面是随分段变化的大标题，右侧是连接状态。底栏去掉。

**头像**

- Agent 是彩色圆角方块加名字的第一个字，颜色由 handle 决定，可以带状态点；本机用户是琥珀色的“你”；群聊是成员的小头像围成的环，最多 5 个，相邻的不重叠（`apps/desktop/src/lib/avatar.ts`、`apps/desktop/src/components/Avatar.tsx`）。
- 聊天里每条消息前有作者的头像；正文里存在的 `@handle` 高亮，规则与 Server 记录点名相同，都用 protocol 的 `mentionPattern`（`apps/desktop/src/lib/mentions.ts`）。

**未读数**

- 新表 `user_read_cursors` 记录用户在每个房间读到的序号；未读数只算别人发的消息（`packages/server/src/conversations.ts`）。
- 界面在房间打开、窗口在前台时把已读位置推进到最新一条（`ChatView.tsx` 的 `useMarkReadWhileOpen`）。
- 已有房间由迁移把已读位置设为当时的最新序号。

**加入群聊**

- 私聊顶栏的“加入群聊…”列出这个 Agent 还不在的群聊，勾选后对每个群聊调用一次已有的加成员接口。

行为与接口见 [messaging.md](../../../../docs/subsystems/messaging.md) 第 5 节。

## 考虑过的方案

**方案 A：左侧导航栏 + 列表 + 内容三栏。** 群聊与联系人各有资料页，以后的“运行观测”“任务”页面在导航栏加图标即可。我推荐了 A，用户选择了 B。

**侧栏顶部用工作区标题。** 绿色方块标志、“Crew”与一行小字（连接状态、本机、几个 agent），右侧是方形的“＋”按钮，像 Slack 与 Linear。我推荐了它，用户选择了大标题的方案。

**侧栏顶部保留“~/crew”。** 改动最小：缩小变灰，“新建”挪到分段右边。没有采用。

**群聊头像用四宫格。** 设计稿最初的画法。用户要求改成环形。

**只显示预览，不做未读数。** 不需要新的表与已读接口。用户要求做未读数。

**顶栏的“群设置”。** 现在没有可设置的内容，不做。

## 后果

- 侧栏保持两栏，界面改动集中在侧栏与聊天的头像；以后加“运行观测”“任务”等页面时，还要另找入口。
- 会话列表每次收到“房间有新消息”都整个重新读取，房间很多时要改为增量更新。
- 窗口在后台时到达的消息算未读；房间开着、窗口在前台时到达的不算。
- Agent 的状态不分房间：它在群聊里回复时，私聊里也显示“正在回复”。
- 测试：未读数与会话列表在 `packages/server/test/api.test.ts` 的 `conversations`；头像位置、预览、@ 高亮与列表时间在 `apps/desktop/test/lib.test.ts`。
