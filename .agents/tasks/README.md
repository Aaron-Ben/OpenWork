# 任务文件

分多块的长任务在这里建一个文件，记录每块的完成标准与进度。进度以文件为准，不以聊天记录为准：对话被压缩或换了会话，读这个文件就能接上。

## 格式

```markdown
# 第 N 步：标题

范围见设计 Agent Note 的对应小节。全部完成后删除本文件。

- [x] 已完成的一块
- [ ] 下一块：一句话说明做什么。
  完成标准：哪些检查通过、能演示什么、已提交。
```

## 规则

- 每块写可以检查的完成标准，做完打勾，与对应的提交一起提交。
- 决策理由写进 Agent Note，不写在这里。
- 全部完成后删除文件。做过什么记录在 git 历史中。
