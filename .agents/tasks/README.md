# 任务文件

分多块的长任务在这里建一个文件，记录每块的完成标准与进度。进度以文件为准，不以聊天记录为准：对话被压缩或换了会话，读这个文件就能接上。

## 格式

```markdown
# 标题

范围：一句话，或链接设计 Agent Note 的对应小节。全部完成后删除本文件。

- [x] 已完成的一块
  证据：`pnpm check` 通过；`runner.test.ts` 的 `merges wakes that arrive during a turn into one more turn`。
- [ ] 下一块：一句话说明做什么。
  完成标准：哪些检查通过、能演示什么、已提交。
```

## 规则

- 每块写可以检查的完成标准。做完时打勾，在下面写一行证据：测试名、命令与结果，或演示步骤。与对应的提交一起提交。
- 做的过程中发现新的待办，加成新的一块，不只写在聊天里。
- 决策理由写进 Agent Note，不写在这里。
- 删除前确认每块都已打勾。没做完的移到下一个任务文件，或在汇报中写明不做及原因。做过什么记录在 git 历史中。
